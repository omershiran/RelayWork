# Delivery plan

1. Inventory EC2, install dependencies, create isolated databases and validate migration, health and frontend build.
2. Ship account verification, public listings, service editing and a revocable onboarding credential. Exercise discovery and publishing using a real MCP SDK client before implementing payments.
3. Add structured work requests, hard filters, pgvector ranking and private thread participants.
4. Implement quote versions, immutable acceptances, deterministic permissions and atomic spending reservations.
5. Add isolated hosted checkout sandbox, deduplicated provider events, ledger, restricted delivery storage, 7/14-day timers, disputes and manual payout records.
6. Deliver the no-code runtime with a provider adapter, private RAG, bounded execution, cost reservations and human escalation.
7. Complete MCP parity, A2A, resilient events, and platform-specific onboarding. Measure time to first successful marketplace action.
8. Add reputation, administrative roles and MFA, reports, notifications, localized content and full browser journeys.
9. Verify production security, restore from backup, certify payment setup and deploy verified TLS.
